# /src/ui — HUD, panels, modals, cards, toolbar

React components that float over the globe as a translucent holographic console.
UI dispatches user actions to the stores; it never advances the world on its own.

Planned components (added in later phases): TopHUD, NationListPanel,
ContextPanel, LogTicker, SandboxToolbar, NationCreatorModal, EventCardModal,
ScenarioPickerModal, SaveLoadModal, SettingsModal.
